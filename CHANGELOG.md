# Changelog

## 0.2.0 candidate — unreleased

### Added

- Installable src-layout package, Qt-free CLI and optional GUI/build/development extras.
- Shared validated configuration, strict JSON profiles and native host/target rules.
- Static dependency inspection and read-only Build Doctor with recovery guidance.
- Explicitly trusted subprocess builds, isolated output, live events, cancellation/timeouts and reports.
- Optional dark/light Qt interface and source-compatible GUI wrapper.
- Reviewed stdlib/Qt examples, automated tests and native CI/release scaffolding.
- Contributor/security/architecture/usage/maintainer/release documentation and genuine Linux offscreen captures.
- Maintainer-authorized MIT project grant, explicit scope notice and PEP 639 license metadata/archive verification.

### Changed

- Removed the prototype's automatic dependency installation and requirements-file rewriting.
- Replaced misleading cross-platform, Python 3.6, missing-entrypoint and placeholder-screenshot instructions.
- Native metadata/settings and selectable console/bundle modes replace hard-coded onefile/windowed output.

### Release limits

- Original icons remain excluded from the MIT grant and distributions pending a usable provenance record; third-party licenses are unchanged.
- PyQt/Qt distribution review and native exact-commit CI/interactive evidence are required before public distribution.
- Frozen PyForge is UI-only until external-interpreter selection exists; source/venv installation is the packaging path.
- CI artifacts are unsigned development output. No PyPI upload/signing/notarization/public release is implied.

## Prototype baseline

Original single-file PyQt5 application and forge assets by Amnas Ahamed. Existing history and the separate README-enhancement branch are preserved. See [audit](docs/AUDIT.md) for the baseline and verification evidence.
